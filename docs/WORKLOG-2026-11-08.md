## 2. 영역별 변경 요약

### 네트워크·인증
- HTTP 로그는 debug 에서만, `Authorization` 헤더 마스킹. 토큰을 출력하던 `LoggingHeaderInterceptor` 삭제.
- `TokenAuthenticator`: 401 → 리프레시 토큰으로 재발급 후 1회 재시도. 동시 401 은 재발급 1회로 처리.
- 리프레시 토큰이 거부(400/401/403)되면 토큰 삭제 + `SessionEvents.expired` → `MainActivity` 가 로그인 화면으로 이동. 네트워크 오류/5xx 는 로그아웃시키지 않음.
- `AuthTokenLock`: `auth/` API 호출과 재발급을 직렬화. `auth/refresh` 응답의 새 토큰은 인터셉터가 락 안에서 즉시 저장.
- `BASE_URL`, `USE_MOCK_API`, `EXTENDED_CATEGORIES` 를 BuildConfig 로 분리.

### 구조
- Remote 데이터소스의 반복 try/catch/로그를 `apiCall`/`requireData` 로 통합.
- 영수증 업로드: domain 은 JPEG `ByteArray`, 리사이즈/인코딩은 presentation(`Bitmap.toResizedJpegBytes`).
- `flowWithResource`: `CancellationException` 재전파, `IOException` → `Resource.STATUS_NETWORK_ERROR`, `UserCancelledException` → `Resource.STATUS_CANCELLED`.

### 기능·UX
- 냉장고: 수정/삭제 실패 스낵바, 새로고침 실패 시 기존 목록 유지.
- 레시피 생성 후 서버 사용량 재조회 → 버튼 활성 상태 갱신.
- 영수증: 미매칭 항목(`{"name","count"}`)을 "소비기한 입력 필요"로 표시, 확인 전 추가 버튼 비활성. 제조일 기준(`dateBasis=LABEL`) 항목은 "소비기한 최대 … · 포장 확인".
- 카테고리 18~22 추가(선택지 노출은 `EXTENDED_CATEGORIES`, 기본 false). 아이콘은 기존 것 임시 사용.
- 로그인 실패 안내를 원인별 문구로(요청 과다/네트워크/서버 오류/일반), 소셜 로그인 취소는 안내하지 않음.
- 에러 화면 재시도 아이콘에 `contentDescription`(스크린리더).

### 앱 시작 흐름
- 온보딩 호출 6회 → 4회: 토큰 검증 호출 제거, 저장된 기본 냉장고 id 가 있으면 조회 생략.
- 온보딩/CSV 초기화는 `start()` 로 화면당 1회, 종료 중인 Activity 에서는 시작하지 않음.
- 프로세스 종료 후 복원 시 저장된 화면 상태를 버리고 온보딩부터 시작.
- CSV 초기화는 프로세스 단위 Mutex 로 직렬화, 재초기화 전 기존 데이터 삭제.

## 5. 환경·운영 메모

- **서버 응답 특성**: 무효 액세스 토큰 → 401, 무효/만료 리프레시 토큰(`auth/refresh`) → 400, 게스트 계정 생성은 IP 당 제한(초과 시 429, 24시간).
- **카카오 로그인 오류**: KOE008(앱 키 종류 오류) → KOE101(키 해시를 앱 키 자리에 입력) → keyHash validation failed(디버그 키 해시 미등록). 네이티브 앱 키는 32자 16진수.
- **Android Studio**: 전역 SDK 경로가 이전 경로(`AppData\Local\Android\Sdk`)를 가리켜 "Missing platform android-35" 발생 → Settings > Android SDK Location 을 `C:\Android\Sdk` 로 변경 필요. "Install missing platform" 은 누르지 말 것.
- **계측 테스트 실행**: `connectedDebugAndroidTest` 는 끝나면 앱을 삭제함. 데이터를 유지하려면 APK 를 `adb install -r` 후 `adb shell am instrument -w -r com.yh.fridgesoksok.test/androidx.test.runner.AndroidJUnitRunner`.
